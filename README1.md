# **IR Sensor-Based Automatic LED Control System**

### **1\. Description**

This project demonstrates an **automatic LED control system using an IR sensor**. The IR sensor detects the presence of an object and provides a signal to control the LED. The circuit is assembled on a breadboard and powered using a DC supply.

### **2\. Components Used**

1. Breadboard  
2. IR Obstacle Sensor Module  
3. Red LED  
4. Resistor  
5. Connecting Wires  
6. DC Power Supply / Battery

### **3\. Procedure**

1. Place the IR sensor module and LED on the breadboard.  
2. Connect the **VCC and GND** of the IR sensor to the power supply.  
3. Connect the sensor's **output pin** to the LED circuit.  
4. Connect a suitable resistor in series with the LED.  
5. Power ON the circuit.  
6. Place an object in front of the IR sensor and observe the LED response.

### **4\. Working**

The **IR sensor continuously emits and detects infrared radiation**.

* When an object comes within the sensing range, the IR radiation is reflected back to the receiver.  
* The sensor detects this change and produces an output signal.  
* This signal controls the LED, causing it to **turn ON/OFF according to the sensor output**.  
* The indicator LED on the sensor module also shows the detection status.

### **5\. Applications**

* Automatic lighting systems  
* Object detection  
* Automatic doors  
* Industrial object counting  
* Security and proximity detection  
* Smart automation systems
